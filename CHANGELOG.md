# Changelog

## 0.2.0 — candidate

- Optional headless editing entry with host-injected history; existing numeric, style, key and drawing operators extracted from the Workbench consumer.
- Source-property projection preserves nested timing, visibility, source keys and immutable revisions without a Timeline or UI dependency.
- Host-shell chrome mode omits duplicate reader controls while retaining selection, import and transform interactions.
- No new runtime dependencies, playback clock or robot semantics.

## 0.1.0 — first release

- Hosted Lottie SVG reading/inspection and optional editing ports.
- Lazy native canvas output, driven by explicit host frames with bounded resources.
- Change reporting for GPU texture invalidation, source cloning and deterministic disposal.
- No autonomous playback, robot semantics or external assets admitted.
